1. ONE-LINE PITCH
================================================================================

Ishaara is an open-source, bi-directional sign language translator that runs
entirely on-device — no GPU, no cloud, no data upload required. It translates
Pakistani Sign Language (PSL) and Indian Sign Language (ISL) into speech and
text in real-time using a webcam, and converts spoken language back into a
3D animated avatar signing in sign language — all within a single browser tab.


================================================================================
2. PROBLEM STATEMENT
================================================================================

Over 15 million deaf individuals in Pakistan and India rely on sign language as
their primary mode of communication. However, the vast majority of the hearing
population does not understand sign language. This creates a critical
communication barrier in hospitals, banks, government offices, classrooms,
and everyday life.

Existing solutions are either:
  - Cloud-dependent (privacy risk, latency, internet required)
  - Unidirectional (sign-to-speech OR speech-to-sign, never both)
  - English-only (no support for South Asian sign languages)
  - Hardware-bound (require gloves, sensors, or specialized cameras)
  - Not user-trainable (cannot adapt to individual signers)

Ishaara solves ALL of these problems in a single, lightweight, browser-based
platform that works offline on any device with a webcam.

3. CORE FEATURES
================================================================================

a) BI-DIRECTIONAL TRANSLATION (THE KEY DIFFERENTIATOR)
   - Sign-to-Speech: Webcam captures hand/body gestures → MediaPipe extracts
     543 body landmarks → ML model predicts the sign → Speech synthesis speaks it
   - Speech-to-Sign: Microphone captures voice → Text → 3D avatar animates
     the corresponding sign language gestures
   - Dual View: Both modes run simultaneously in a split-screen layout

b) ON-DEVICE MACHINE LEARNING (ZERO CLOUD DEPENDENCY)
   - MediaPipe Holistic: 543-point full-body landmark tracking
     (33 pose + 42 hand + 468 face landmarks per frame)
   - Shoulder-width normalization: Works regardless of camera distance or
     person's body size
   - Sliding window inference: 24-frame temporal window for gesture recognition
   - Two model architectures:
     * MLP (Multi-Layer Perceptron): Lightweight, instant inference
     * GRU (Gated Recurrent Unit): Temporal model, higher accuracy
   - Pure JavaScript inference — no TensorFlow.js, no ONNX, no GPU required

c) USER-TRAINABLE SYSTEM (UNIQUE — NO OTHER PROJECT DOES THIS)
   - Record your own signs via webcam (8-12 takes per gesture)
   - Export dataset as JSON
   - Train model with a single Python command (NumPy-only, zero dependencies)
   - Deploy trained model back into the browser
   - Anyone can teach Ishaara their regional dialect or personal signs

d) 3D PROCEDURAL AVATAR
   - Entirely code-generated humanoid (no external 3D model files)
   - Built with Three.js geometry primitives
   - Customizable: skin tone, hair style, outfit
   - Animated signing gestures with smooth easing
   - Runs on any device with WebGL support

e) GEMINI 2.5 FLASH NLP INTEGRATION
   - Cloud-quality grammar parsing for text-to-gloss conversion
   - Converts English/Urdu sentences into sign language gloss order (SVO → SOV)
   - Automatic fallback to local rules when offline or API unavailable

f) SOUTH ASIAN LANGUAGE SUPPORT
   - Pakistani Sign Language (PSL)
   - Indian Sign Language (ISL)
   - English + Urdu + Hindi text/speech
   - Massively underserved market — no comparable open-source tool exists

9. TRAINING & INFERENCE DETAILS
================================================================================

MODEL 1 — MLP (Multi-Layer Perceptron)
  Input:    450 features (per-coordinate mean + std over 24 frames)
  Hidden:   Linear(450→64) + ReLU
  Output:   Linear(64→NumClasses) + Softmax
  Training: Mini-batch SGD with momentum, lr=0.05, 80 epochs
  Runtime:  <1ms inference per frame (CPU only)

MODEL 2 — GRU (Gated Recurrent Unit)
  Input:    1629 values per frame (543 landmarks × 3 coords)
  Embedding: Linear(1629→128)
  Recurrent: GRU(128→256, 2 layers)
  Output:   Linear(256→NumClasses)
  Runtime:  ~2ms inference per frame (CPU only)

TRAINING DATA:
  10 starter gestures: HELLO, THANK-YOU, PLEASE, SORRY, YES, NO,
                        GOOD, BAD, NAME, WATER
  Custom labels supported via browser recording UI
  24 frames per gesture capture (15fps webcam)

NORMALIZATION:
  Shoulder-width normalization ensures distance-agnostic predictions.
  Works regardless of camera distance or person's body size.
